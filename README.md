# Web3 Security Labs

This repository contains three labs demonstrating common security vulnerabilities in Web3 applications:

## Labs Overview

1. **Lab 1: Double-Spending in GameFi** - Shows how missing transaction locks can lead to double-spending exploits
2. **Lab 2: Insecure Logging in Web3 App** - Illustrates how poor logging practices can expose sensitive data

Each lab contains:

- A README explaining the vulnerability
- Code examples showing the vulnerability
- Remediation steps to fix the issue

## Getting Started

Navigate to each lab directory to learn more about specific vulnerabilities:

```
cd lab1-double-spending
cd lab2-insecure-logging
```
